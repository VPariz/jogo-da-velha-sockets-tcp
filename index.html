Especificação: Estrutura do Tabuleiro

Representação do Tabuleiro em Memória

Decisão de arquitetura em C: Por que utilizamos um vetor linear char tabuleiro[9] em vez de uma matriz bidimensional?

Definição dos Dados
// Convencao de simbolos da especificacao
#define SIMBOLO_SERVIDOR 'O'
#define SIMBOLO_CLIENTE  'X'

// Vetor linear alocado na pilha (stack)
char tabuleiro[9];

// Inicializacao com caracteres de espaco em branco
for (int i = 0; i < 9; i++) {
    tabuleiro[i] = ' ';
}

Vantagens Técnicas de tabuleiro[9]

  • Mapeamento em $O(1)$ Direto: A entrada do jogador é um número entre 1 e 9. O acesso ao vetor ocorre diretamente em tabuleiro[jogada - 1], eliminando divisões inteiras e operações de módulo (linha = (n-1)/3, coluna = (n-1)%3).
  • Passagem Eficiente de Parâmetro: Passado às rotinas por referência simples (const char tab[9]), consumindo apenas 8 bytes de ponteiro no registrador de arquitetura x64.
  • Contiguidade de Memória: O bloco contíguo de 9 bytes otimiza o uso do cache L1 do processador durante a varredura das linhas de término.
Módulo 2 • Descoberta de Rede

Função exibir_ips_locais()

Inspeção programática das interfaces de rede locais para conexão direta sem comandos de sistema:

servidor_velha.c (Linhas 39 a 56)
void exibir_ips_locais(int porta) {
    char hostname[256];
    gethostname(hostname, sizeof(hostname));
    struct hostent *host_info = gethostbyname(hostname);

    if (host_info != NULL && host_info->h_addr_list != NULL) {
        for (int i = 0; host_info->h_addr_list[i] != NULL; i++) {
            struct in_addr addr;
            memcpy(&addr, host_info->h_addr_list[i], sizeof(struct in_addr));
            printf("       -> %s (Rede Local)\n", inet_ntoa(addr));
        }
    }
}

Estrutura Interna de Resolução

A estrutura hostent disponibiliza o membro h_addr_list, um ponteiro duplo para endereços binários IPv4 finalizado em NULL. A função itera sobre todas as interfaces ativas (Wi-Fi, Ethernet, adaptadores virtuais), copia os 4 bytes para uma estrutura in_addr e converte em texto decimal pontuado via inet_ntoa().

Tratamento de Vulnerabilidades em C

  • Inadequação do scanf: Caso caracteres não numéricos sejam digitados, scanf("%d") falha na conversão, deixa os bytes no buffer stdin e gera um laço de repetição infinito.
  • Delimitação Estrita com fgets: Limita a leitura a 127 caracteres úteis mais o terminador '\0', neutralizando riscos de estouro de memória.
  • Rotina de Dreno com getchar(): Caso uma sequência excessivamente longa seja inserida, o dreno descarta o restante da linha até a próxima quebra, evitando contaminação de rodadas futuras.
Especificação: Validação de Caracteres e Ocupação

Função obter_jogada_usuario() (Parte 2: Trim e Validação)

Normalização de terminação de linha, eliminação de espaços e validação de ocupação:

Continuação da Função
        // 1. Remove terminadores de linha Windows (\r\n) ou Unix (\n)
        linha[strcspn(linha, "\r\n")] = '\0';

        // 2. Normalizacao (Trim) de espacos e tabs a esquerda
        char *inicio = linha;
        while (*inicio == ' ' || *inicio == '\t') inicio++;

        // 3. Normalizacao (Trim) de espacos e tabs a direita
        char *fim = inicio + strlen(inicio) - 1;
        while (fim > inicio && (*fim == ' ' || *fim == '\t')) {
            *fim = '\0';
            fim--;
        }

        // 4. Exige EXATAMENTE 1 unico caractere numerico de '1' a '9'
        if (strlen(inicio) != 1 || inicio[0] < '1' || inicio[0] > '9') {
            printf("Entrada invalida! Digite apenas um unico numero de 1 a 9.\n");
            continue;
        }

        celula = (inicio[0] - '1'); // Mapeamento para indice 0 a 8

        // 5. Verificacao de celula previamente ocupada
        if (tabuleiro[celula] != ' ') {
            printf("Posicao invalida! A celula %d ja esta ocupada (%c).\n",
                   celula + 1, tabuleiro[celula]);
            continue;
        }

        return celula + 1;

Garantias da Validação

  • Robustez contra Espaços: Entradas como " 5 " são devidamente limpas e aceitas sem falhas.
  • Rejeição de Múltiplos Caracteres: Entradas compostas (ex: "12", "abc" ou "1 2") são bloqueadas pela condição strlen(inicio) != 1.
  • Conversão Aritmética de Ponteiro: O cálculo inicio[0] - '1' mapeia os valores ASCII contíguos (códigos 49 a 57) no índice inteiro 0-8 de forma atômica e eficiente.
Especificação: Verificação de Vitória e Empate

Função verificar_termino(): Matriz das 8 Retas

Algoritmo em $O(1)$ determinístico que avalia as 8 linhas de vitória e a condição de empate:

servidor_velha.c / cliente_velha.c (Linhas 90 a 117)
int verificar_termino(const char tab[9]) {
    // As 8 combinacoes vitoriosas possiveis
    const int linhas[8][3] = {
        {0, 1, 2}, {3, 4, 5}, {6, 7, 8}, // 3 Horizontais
        {0, 3, 6}, {1, 4, 7}, {2, 5, 8}, // 3 Verticais
        {0, 4, 8}, {2, 4, 6}             // 2 Diagonais
    };

    for (int i = 0; i < 8; i++) {
        int a = linhas[i][0], b = linhas[i][1], c = linhas[i][2];
        if (tab[a] != ' ' && tab[a] == tab[b] && tab[b] == tab[c]) {
            if (tab[a] == 'X') return 1; // Vitoria do Cliente ('X')
            if (tab[a] == 'O') return 2; // Vitoria do Servidor ('O')
        }
    }

    // Se resta espaco vazio, a partida continua
    for (int i = 0; i < 9; i++) {
        if (tab[i] == ' ') return -1;
    }

    return 0; // Todas as celulas preenchidas sem vencedor: Empate ("Deu velha")
}
🛡️ Validação Distribuída e Autônoma: Em consonância com o projeto, ambos os nós realizam a checagem localmente. Nenhum nó depende de confirmação remota sobre o desfecho da rodada, assegurando integridade à máquina de estados.
Especificação: Conexão e Isolamento de Sessão

Configuração do Servidor e Fechamento do Listener

Gerenciamento do descritor passivo e alocação do socket de transferência:

servidor_velha.c (Linhas 220 a 273)
// 1. Alocacao do socket passivo TCP
listen_sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);

// 2. Mitigacao de bloqueio de porta no reinicio (TIME_WAIT)
int opt = 1;
setsockopt(listen_sd, SOL_SOCKET, SO_REUSEADDR, (const char *)&opt, sizeof(opt));

// 3. Vinculo com porta local e definicao de fila (backlog = 1)
bind(listen_sd, (struct sockaddr *)&servAddr, sizeof(servAddr));
listen(listen_sd, 1);

// 4. Accept bloqueia ate o handshake de 3 vias se completar
client_sd = accept(listen_sd, (struct sockaddr *)&cliAddr, &cliLen);

// 5. Fechamento imediato do socket de escuta!
closesocket(listen_sd);
listen_sd = INVALID_SOCKET;

Decisão de Engenharia de Redes

O socket listen_sd tem a função restrita de aguardar o pacote inicial SYN. Uma vez que o método accept() estabelece o circuito virtual e retorna o socket de dados client_sd, o descritor passivo torna-se dispensável.

O fechamento imediato com closesocket(listen_sd) libera a porta local no kernel e impede conexões adicionais não autorizadas durante a partida.

Recepção Síncrona no Nó Cliente (cliente_velha.c)

O nó Cliente permanece em estado bloqueante na chamada recv(sd, buffer, sizeof(buffer)-1, 0) aguardando a decisão arbitral. Ao receber o pacote, analisa a ocorrência da substring START:CLIENT via strstr(), ajustando sua variável booleana de estado (vez_do_cliente = 1 ou 0).

Especificação: Resiliência de Rede e Término

Tratamento de Desconexão e Liberação de Recursos

Tratamento dos 3 casos de retorno de recv() e desalocação Winsock:

🟢

rc > 0 (Sucesso)

Leitura normal de bytes. O código insere buffer[rc] = '\0' para garantir a integridade de string antes do parsing via sscanf.

🟡

rc == 0 (Término Gracioso)

Indica encerramento voluntário pelo outro processo através de transmissão do pacote TCP FIN. O loop é interrompido sem alarme de falha.

🔴

rc < 0 (Queda Abrupta)

Interrupção anormal da conexão (ex: reset TCP ou falha no meio físico). O código captura o código numérico via WSAGetLastError(). 

Desalocação Ordenada de Recursos
if (client_sd != INVALID_SOCKET) {
    closesocket(client_sd); // Transmite o pacote TCP FIN e fecha o descritor
}
WSACleanup();                // Decrementa o contador de referencias e libera ws2_32.dll
getchar();                   // Mantem o console aberto para inspecao final da partida
