Visão Geral

Como o Jogo Funciona na Rede

O jogo coloca dois computadores em disputa direta através de uma conexão TCP confiável na porta 6000:

Papéis de Cada Lado

  • Servidor (Peça 'O'): É iniciado primeiro, aguarda conexões e descobre seus IPs locais automaticamente.
  • Cliente (Peça 'X'): Inicia em seguida, conecta ao IP do servidor e aguarda o sorteio.
  • Sorteio Inicial: O servidor joga uma moeda (rand() % 2) e avisa quem começa.

Troca de Mensagens (Protocolo)

  • START:SERVER ou START:CLIENT: Enviado no início para sincronizar a ordem.
  • MOVE:<1-9>: Enviado a cada jogada com a célula escolhida (ex: MOVE:5\n).
  • Validação Local: Ambos os programas atualizam o tabuleiro e checam vitória/empate localmente.
servidor_velha.c

O Nó Servidor: Conexão e Sorteio

Como o servidor inicializa a rede, aguarda o cliente e sorteia quem começa:

// 1. Cria o socket TCP e aguarda conexao
listen_sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
bind(listen_sd, (struct sockaddr *)&servAddr, sizeof(servAddr));
listen(listen_sd, 1);

// 2. Bloqueia ate o cliente conectar
client_sd = accept(listen_sd, (struct sockaddr *)&cliAddr, &cliLen);
closesocket(listen_sd); // Fecha o listener, jogo eh para 2!

// 3. Sorteio aleatorio da moeda
srand((unsigned)time(NULL));
int vez_do_servidor = rand() % 2;

// 4. Envia mensagem de inicio ao cliente
if (vez_do_servidor)
    send(client_sd, "START:SERVER\n", 13, 0);
else
    send(client_sd, "START:CLIENT\n", 13, 0);

Pontos Importantes do Código

  • SO_REUSEADDR: Usamos setsockopt para liberar a porta 6000 imediatamente se precisarmos reiniciar o servidor.
  • Fechamento do Listener: Logo após o accept(), fechamos listen_sd porque a partida já tem 2 jogadores. Isso economiza recursos e bloqueia conexões invasoras.
  • Sorteio Imparcial: O time(NULL) garante que cada partida tenha um resultado genuinamente imprevisível.
cliente_velha.c

O Nó Cliente: Conexão e Sincronia

Como o cliente se conecta ao servidor e descobre se joga primeiro:

// 1. Entrada flexivel de IP (argumento ou prompt)
if (strlen(server_ip_str) == 0) {
    printf("Digite o IP do servidor [Enter para 127.0.0.1]: ");
    fgets(server_ip_str, sizeof(server_ip_str), stdin);
    // Se teclar Enter -> conecta na mesma maquina
}

// 2. Conecta ao servidor TCP
sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
connect(sd, (struct sockaddr *)&servAddr, sizeof(servAddr));

// 3. Aguarda o resultado do sorteio da moeda
recv(sd, buffer, sizeof(buffer) - 1, 0);

if (strstr(buffer, "START:CLIENT")) {
    vez_do_cliente = 1; // Voce comeca!
} else {
    vez_do_cliente = 0; // Servidor comeca
}

Facilidade para a Apresentação

  • Sem Recompilar: Para jogar entre computadores diferentes no laboratório, basta passar o IP (ex: .\cliente_velha.exe 172.16.1.160).
  • Teste Local com 1 Clique: Se estiver no mesmo PC, basta dar Enter e o código assume 127.0.0.1 automaticamente.
  • Bloqueio no recv(): O cliente não toma nenhuma decisão até que o servidor termine o sorteio e envie a mensagem de controle.
A Máquina de Estados

O Ciclo de Turnos: Envio e Recepção

O coração do jogo é um laço while (jogo_ativo) que alterna entre quem joga e quem aguarda:

// === QUANDO EH A MINHA VEZ ===
if (minha_vez) {
    // 1. Le e valida a jogada (1 a 9)
    int jogada = obter_jogada_usuario(tabuleiro, MEU_SIMBOLO);
    tabuleiro[jogada - 1] = MEU_SIMBOLO;
    exibir_tabuleiro(tabuleiro);

    // 2. Envia a coordenada pela rede
    snprintf(buffer, sizeof(buffer), "MOVE:%d\n", jogada);
    send(socket_sd, buffer, strlen(buffer), 0);

    // 3. Checa se o jogo acabou
    if (verificar_termino(tabuleiro) != -1)
        jogo_ativo = 0;
    minha_vez = 0; // Passa a vez
}

// === QUANDO EH A VEZ DO ADVERSARIO ===
else {
    printf("Aguardando jogada do adversario...\n");

    // 1. Bloqueia ate receber dados da rede
    int rc = recv(socket_sd, buffer, sizeof(buffer)-1, 0);

    if (rc > 0) {
        buffer[rc] = '\0';
        int jogada_adv;
        sscanf(buffer, "MOVE:%d", &jogada_adv);

        // 2. Marca no tabuleiro local
        tabuleiro[jogada_adv - 1] = SIMBOLO_ADV;
        exibir_tabuleiro(tabuleiro);

        // 3. Checa se o jogo acabou
        if (verificar_termino(tabuleiro) != -1)
            jogo_ativo = 0;
        minha_vez = 1; // Agora eh a minha vez!
    }
}
verificar_termino()

Lógica de Vitória e Empate

A função que avalia as 8 linhas de vitória e a ocorrência de empate em tempo constante $O(1)$:

int verificar_termino(const char tab[9]) {
    // Matriz com as 8 retas possiveis de vitoria
    const int linhas[8][3] = {
        {0, 1, 2}, {3, 4, 5}, {6, 7, 8}, // 3 Horizontais
        {0, 3, 6}, {1, 4, 7}, {2, 5, 8}, // 3 Verticais
        {0, 4, 8}, {2, 4, 6}             // 2 Diagonais
    };

    // 1. Checa se alguem fechou uma reta
    for (int i = 0; i < 8; i++) {
        int a = linhas[i][0], b = linhas[i][1], c = linhas[i][2];
        if (tab[a] != ' ' && tab[a] == tab[b] && tab[b] == tab[c]) {
            if (tab[a] == 'X') return 1; // Vitoria de X
            if (tab[a] == 'O') return 2; // Vitoria de O
        }
    }

    // 2. Se ha casa vazia, o jogo continua
    for (int i = 0; i < 9; i++) {
        if (tab[i] == ' ') return -1;
    }

    return 0; // Todas cheias sem vencedor: Empate!
}

Como Tratamos o Encerramento

  • Validação Independente: Servidor e Cliente executam essa função em seus computadores. Nenhum nó precisa mandar mensagem de "você perdeu" — o tabuleiro decide.
  • Mensagens na Tela:
    • Se status for minha vitória: "Você venceu!"
    • Se status for do oponente: "Você perdeu!"
    • Se status for 0: "Empate!"
  • Fechamento: Logo após, chamamos closesocket() e WSACleanup().

Validação e Sanitização de Entrada

Como garantimos que o jogo não trave e rejeite qualquer digitação incorreta:

// 1. Leitura segura com fgets (evita estouro de buffer)
fgets(linha, sizeof(linha), stdin);

// 2. Se digitou mais de 127 caracteres, drena o buffer
if (strchr(linha, '\n') == NULL) {
    int c;
    while ((c = getchar()) != '\n' && c != EOF);
}

// 3. Remove quebras de linha e espacos nas bordas
linha[strcspn(linha, "\r\n")] = '\0';

// 4. Exige EXATAMENTE 1 unico caractere de '1' a '9'
if (strlen(inicio) != 1 || inicio[0] < '1' || inicio[0] > '9') {
    printf("Entrada invalida! Digite apenas de 1 a 9.\n");
    continue;
}

// 5. Impede jogar em casa ja ocupada
if (tabuleiro[celula] != ' ') {
    printf("Posicao ocupada! Escolha outra.\n");
    continue;
}

Por que NÃO usamos scanf("%d")?

  • O Problema do scanf: Se o usuário digitar acidentalmente uma letra (ex: "a"), o scanf falha, não consome a entrada e o programa entra em loop infinito.
  • A Solução com fgets: Lemos a linha como texto, limpamos os espaços e validamos se é exatamente um dígito entre 1 e 9.
  • Proteção de Célula: O código checa tabuleiro[celula] != ' ' antes de aceitar a jogada.
