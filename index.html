Fluxo de Conexão e Troca de Mensagens

Visão completa do ciclo de vida: o Servidor aguarda na porta 6000 e o Cliente conecta diretamente via TCP:

Etapa 1 • Conexão TCP

Estabelecendo a Conexão: Servidor vs Cliente

Comparação direta do momento em que o servidor abre a porta e o cliente se conecta:

SERVIDOR (servidor_velha.c) Escuta Passiva 
// 1. Cria socket passivo na porta 6000
listen_sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
bind(listen_sd, (struct sockaddr *)&servAddr, sizeof(servAddr));
listen(listen_sd, 1);

// 2. Bloqueia ate o cliente conectar
client_sd = accept(listen_sd, (struct sockaddr *)&cliAddr, &cliLen);

// 3. Fecha escuta (jogo exclusivo para 2)
closesocket(listen_sd);
CLIENTE (cliente_velha.c) Conexão Ativa 
// 1. Pergunta o IP (Enter = 127.0.0.1)
if (strlen(ip_str) == 0) {
    printf("IP do servidor [Enter p/ 127.0.0.1]: ");
    fgets(ip_str, sizeof(ip_str), stdin);
}

// 2. Cria socket e conecta ao servidor
sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
connect(sd, (struct sockaddr *)&servAddr, sizeof(servAddr));
// Conexao estabelecida com sucesso!
💡
Interação na Rede: Enquanto o servidor pausa no accept(), o cliente dispara o connect(). Logo após aceitar o cliente, o servidor fecha o socket de escuta (listen_sd) para proteger a partida contra outras conexões.
Etapa 2 • Sincronismo Inicial

Sorteio de Quem Começa: Servidor vs Cliente

O servidor joga a moeda (0 ou 1) e avisa o cliente via rede antes do jogo começar:

SERVIDOR (servidor_velha.c) Sorteia e Envia 
// 1. Sorteio aleatorio da moeda
srand((unsigned)time(NULL));
int vez_do_servidor = rand() % 2;

// 2. Envia mensagem de controle pela rede
if (vez_do_servidor) {
    send(client_sd, "START:SERVER\n", 13, 0);
    minha_vez = 1; // Servidor comeca
} else {
    send(client_sd, "START:CLIENT\n", 13, 0);
    minha_vez = 0; // Cliente comeca
}
CLIENTE (cliente_velha.c) Aguarda e Interpreta 
// 1. Bloqueia no recv aguardando sorteio
recv(sd, buffer, sizeof(buffer) - 1, 0);

// 2. Interpreta qual comando recebeu
if (strstr(buffer, "START:CLIENT")) {
    printf("Voce comeca jogando (X)!\n");
    minha_vez = 1; // Minha vez
} else {
    printf("O servidor comeca jogando (O)!\n");
    minha_vez = 0; // Aguardo o servidor
}
💡
Sincronia Estrita: O cliente não toma decisões locais sobre a ordem; ele fica no recv() até o pacote de controle chegar. Assim, ambos iniciam perfeitamente alinhados sobre quem é o jogador ativo.
Etapa 3 • Laço Principal

Alternância de Jogadas: Meu Turno vs Turno Oponente

Estrutura simétrica do laço while (jogo_ativo) presente em ambos os programas:

QUANDO É A MINHA VEZ Jogador Ativo (Envia) 
// 1. Le e valida a jogada de 1 a 9
int jogada = obter_jogada_usuario(tabuleiro, MEU_SIMBOLO);
tabuleiro[jogada - 1] = MEU_SIMBOLO;
exibir_tabuleiro(tabuleiro);

// 2. Envia a jogada pela rede
snprintf(buffer, sizeof(buffer), "MOVE:%d\n", jogada);
send(socket_sd, buffer, strlen(buffer), 0);

// 3. Checa termino e passa a vez
if (verificar_termino(tabuleiro) != -1) jogo_ativo = 0;
minha_vez = 0;
QUANDO É A VEZ DO OPONENTE Jogador Passivo (Aguardando) 
printf("Aguardando a jogada do oponente...\n");

// 1. Bloqueia no recv ate a jogada chegar
int rc = recv(socket_sd, buffer, sizeof(buffer)-1, 0);
buffer[rc] = '\0';

// 2. Extrai coordenada e marca no tabuleiro
int jogada_adv;
sscanf(buffer, "MOVE:%d", &jogada_adv);
tabuleiro[jogada_adv - 1] = SIMBOLO_ADV;
exibir_tabuleiro(tabuleiro);

// 3. Checa termino e assume a vez
if (verificar_termino(tabuleiro) != -1) jogo_ativo = 0;
minha_vez = 1;
💡
Simetria do Protocolo: O protocolo MOVE:<1-9> é idêntico nos dois sentidos. Quando um lado envia, o outro está aguardando no recv(). Ao receber, ambos atualizam seus tabuleiros de forma determinística.
Etapa 4 • Regras do Jogo

Como os Nós Avaliam Vitória e Empate

Função executada localmente por ambos os nós para verificar as 8 combinações vencedoras:

LÓGICA COMPARTILHADA verificar_termino() 
int verificar_termino(const char tab[9]) {
    const int L[8][3] = {
        {0,1,2}, {3,4,5}, {6,7,8}, // 3 Linhas
        {0,3,6}, {1,4,7}, {2,5,8}, // 3 Colunas
        {0,4,8}, {2,4,6}             // 2 Diagonais
    };

    // 1. Confere se alguma reta tem 3 pecas iguais
    for (int i = 0; i < 8; i++) {
        if (tab[L[i][0]] != ' ' &&
            tab[L[i][0]] == tab[L[i][1]] &&
            tab[L[i][1]] == tab[L[i][2]])
            return (tab[L[i][0]] == 'X') ? 1 : 2;
    }

    // 2. Se restar alguma casa vazia, segue o jogo
    for (int i = 0; i < 9; i++) {
        if (tab[i] == ' ') return -1;
    }

    return 0; // Tabuleiro cheio sem vencedor: Deu velha!
}

Validação Local Determinística

  • Sem Pacotes Extras: Como ambos os computadores mantêm seus tabuleiros rigorosamente iguais, nenhum nó precisa mandar mensagem dizendo "eu ganhei". O próprio código local identifica o término.
  • Retornos da Função:
    • 1: Vitória de 'X' (Cliente)
    • 2: Vitória de 'O' (Servidor)
    • 0: Empate (deu velha)
    • -1: Partida continua em andamento
  • Encerramento: Ao detectar término (retorno $\neq -1$), o laço finaliza e os sockets são fechados com closesocket().
Etapa 5 • Sanitização

Leitura Segura: Evitando Travamentos

Como a função obter_jogada_usuario() trata a entrada do teclado para não quebrar o programa:

LÓGICA COMPARTILHADA obter_jogada_usuario() 
// 1. Leitura segura com fgets (evita travar se digitar letras)
fgets(linha, sizeof(linha), stdin);

// 2. Remove quebras de linha e espacos extras
linha[strcspn(linha, "\r\n")] = '\0';

// 3. Exige exatamente um digito de '1' a '9'
if (strlen(linha) != 1 || linha[0] < '1' || linha[0] > '9') {
    printf("Entrada invalida! Digite apenas de 1 a 9.\n");
    continue; // Pede para digitar novamente
}

// 4. Converte o caractere no indice do vetor (0 a 8)
int celula = linha[0] - '1';

// 5. Nao permite jogar em casa ja preenchida
if (tabuleiro[celula] != ' ') {
    printf("Posicao ja ocupada! Escolha outra casa.\n");
    continue;
}

Por que não usamos scanf("%d")?

  • O Problema do scanf: Se o usuário digitar acidentalmente uma letra (ex: a) ou palavra, o scanf falha, não consome a entrada do buffer do teclado e o programa entra em loop infinito.
  • A Vantagem do fgets: Lê a linha inteira como texto. Qualquer caractere indesejado é tratado com calma e o programa apenas pede o número de novo.
  • Subtrair '1': Como os caracteres '1' a '9' são sequenciais na tabela ASCII, subtrair '1' converte diretamente para o índice de 0 a 8 do nosso vetor.
  • Célula Livre: Checa tabuleiro[celula] != ' ' antes de aceitar.
