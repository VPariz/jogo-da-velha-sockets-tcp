Visão Geral

Como Funciona o Jogo na Rede

Dois computadores disputam uma partida conectando-se diretamente via TCP na porta 6000:

Papel de Cada Programa

  • Servidor (Peça 'O'): É aberto primeiro, libera a porta 6000 e fica aguardando o adversário se conectar.
  • Cliente (Peça 'X'): É aberto em seguida, conecta no IP do servidor e aguarda o início.
  • Sorteio Inicial: O servidor joga a moeda (rand() % 2) e avisa quem faz a primeira jogada.

Mensagens Trocadas (Protocolo Simples)

  • START:SERVER ou START:CLIENT: Enviado uma única vez no início para sincronizar quem começa.
  • MOVE:<1-9>: Enviado a cada jogada com o número da casa escolhida (exemplo: MOVE:5\n).
  • Tabuleiro Local: Cada computador atualiza sua tela e confere vitória ou empate após cada movimento.
Fluxo de Comunicação

Conexão e Troca de Mensagens

Passo a passo das chamadas de sockets durante uma partida:

servidor_velha.c

Servidor: Inicialização e Sorteio

Como o servidor prepara o socket, aguarda o cliente e sorteia quem começa:

// 1. Cria o socket TCP e escuta na porta 6000
listen_sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
bind(listen_sd, (struct sockaddr *)&servAddr, sizeof(servAddr));
listen(listen_sd, 1);

// 2. Aguarda o cliente conectar
client_sd = accept(listen_sd, (struct sockaddr *)&cliAddr, &cliLen);
closesocket(listen_sd); // Fecha a escuta: ja temos os 2 jogadores

// 3. Sorteia quem comeca a jogar
srand((unsigned)time(NULL));
int vez_do_servidor = rand() % 2;

// 4. Avisa o cliente quem foi o sorteado
if (vez_do_servidor)
    send(client_sd, "START:SERVER\n", 13, 0);
else
    send(client_sd, "START:CLIENT\n", 13, 0);

O que essa parte faz

  • socket, bind, listen: Inicializa a rede e coloca a porta 6000 pronta para receber uma conexão.
  • accept(): O servidor pausa nessa linha até o cliente conectar. Quando conecta, cria um socket específico para a conversa (client_sd).
  • closesocket(listen_sd): Como a partida é exclusiva entre 2 jogadores, não precisamos aceitar mais ninguém, então fechamos a escuta.
  • Sorteio: rand() % 2 gera 0 ou 1 para decidir de forma justa quem começa.
cliente_velha.c

Cliente: Conexão e Início

Como o cliente localiza o servidor e descobre se começa jogando:

// 1. Entrada de IP (se teclar Enter, usa 127.0.0.1)
if (strlen(server_ip_str) == 0) {
    printf("Digite o IP do servidor [Enter para 127.0.0.1]: ");
    fgets(server_ip_str, sizeof(server_ip_str), stdin);
}

// 2. Conecta ao servidor TCP na porta 6000
sd = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
connect(sd, (struct sockaddr *)&servAddr, sizeof(servAddr));

// 3. Aguarda a mensagem com o resultado do sorteio
recv(sd, buffer, sizeof(buffer) - 1, 0);

if (strstr(buffer, "START:CLIENT")) {
    vez_do_cliente = 1; // Voce comeca jogando!
} else {
    vez_do_cliente = 0; // O servidor comeca
}

O que essa parte faz

  • IP Flexível: O cliente pode receber o IP por linha de comando (ex: .\cliente_velha 192.168.1.15) ou digitando na hora.
  • Teste Rápido no Mesmo PC: Se apenas apertar Enter, o programa assume 127.0.0.1 automaticamente, facilitando testar em uma máquina só.
  • connect(): Dispara o pedido de conexão TCP com o servidor.
  • recv(): Fica aguardando a mensagem do servidor informando quem começa a rodada.
Lógica do Jogo

Alternância de Turnos

Um laço while (jogo_ativo) que alterna entre quem faz a jogada e quem fica esperando:

// === QUANDO EH A MINHA VEZ ===
if (minha_vez) {
    // 1. Le e valida a jogada (1 a 9)
    int jogada = obter_jogada_usuario(tabuleiro, MEU_SIMBOLO);
    tabuleiro[jogada - 1] = MEU_SIMBOLO;
    exibir_tabuleiro(tabuleiro);

    // 2. Envia a jogada pela rede
    snprintf(buffer, sizeof(buffer), "MOVE:%d\n", jogada);
    send(socket_sd, buffer, strlen(buffer), 0);

    // 3. Checa se o jogo acabou
    if (verificar_termino(tabuleiro) != -1)
        jogo_ativo = 0;
    minha_vez = 0; // Passa a vez para o outro
}

// === QUANDO EH A VEZ DO ADVERSARIO ===
else {
    printf("Aguardando a jogada do oponente...\n");

    // 1. Pausa no recv ate chegar a jogada
    int rc = recv(socket_sd, buffer, sizeof(buffer)-1, 0);

    if (rc > 0) {
        buffer[rc] = '\0';
        int jogada_adv;
        sscanf(buffer, "MOVE:%d", &jogada_adv);

        // 2. Marca no tabuleiro local
        tabuleiro[jogada_adv - 1] = SIMBOLO_ADV;
        exibir_tabuleiro(tabuleiro);

        // 3. Checa se o jogo acabou
        if (verificar_termino(tabuleiro) != -1)
            jogo_ativo = 0;
        minha_vez = 1; // Agora eh a minha vez
    }
}
verificar_termino()

Como o Código Verifica Vitória e Empate

A função percorre as 8 retas possíveis de vitória e checa se ainda restam casas vazias:

int verificar_termino(const char tab[9]) {
    // As 8 retas possiveis de vitoria
    const int linhas[8][3] = {
        {0, 1, 2}, {3, 4, 5}, {6, 7, 8}, // 3 Linhas
        {0, 3, 6}, {1, 4, 7}, {2, 5, 8}, // 3 Colunas
        {0, 4, 8}, {2, 4, 6}             // 2 Diagonais
    };

    // 1. Confere se alguma reta tem 3 pecas iguais
    for (int i = 0; i < 8; i++) {
        int a = linhas[i][0], b = linhas[i][1], c = linhas[i][2];
        if (tab[a] != ' ' && tab[a] == tab[b] && tab[b] == tab[c]) {
            if (tab[a] == 'X') return 1; // Vitoria de X
            if (tab[a] == 'O') return 2; // Vitoria de O
        }
    }

    // 2. Se houver alguma casa vazia, o jogo continua
    for (int i = 0; i < 9; i++) {
        if (tab[i] == ' ') return -1;
    }

    return 0; // Tabuleiro cheio sem vencedor: Deu velha!
}

O que essa parte faz

  • Validação Local: Tanto o Servidor quanto o Cliente executam essa função após cada jogada. Como ambos mantêm o mesmo tabuleiro sincronizado, chegam ao mesmo resultado sem precisar de mensagens extras.
  • Valores de Retorno:
    • 1: Vitória de 'X' (Cliente)
    • 2: Vitória de 'O' (Servidor)
    • 0: Empate (deu velha)
    • -1: Jogo segue em andamento
  • Fim de Jogo: Quando o retorno é diferente de -1, o jogo encerra o laço e fecha a conexão.
obter_jogada_usuario()

Entrada Segura: Evitando Travamentos

Como o código trata o que o usuário digita para não quebrar a execução:

// 1. Leitura segura com fgets (evita travar se digitar letras)
fgets(linha, sizeof(linha), stdin);

// 2. Remove quebras de linha e espacos extras
linha[strcspn(linha, "\r\n")] = '\0';

// 3. Exige exatamente um digito de '1' a '9'
if (strlen(inicio) != 1 || inicio[0] < '1' || inicio[0] > '9') {
    printf("Entrada invalida! Digite apenas de 1 a 9.\n");
    continue; // Pede para digitar novamente
}

// 4. Converte o caractere no indice do vetor (0 a 8)
int celula = inicio[0] - '1';

// 5. Nao permite jogar em casa ja preenchida
if (tabuleiro[celula] != ' ') {
    printf("Posicao ja ocupada! Escolha outra casa.\n");
    continue;
}

Por que não usamos scanf("%d")?

  • O Problema do scanf: Se o usuário digitar acidentalmente uma letra (como 'a' ou uma palavra inteira), o scanf("%d") falha, não remove os caracteres do teclado e o programa entra em loop infinito.
  • A Vantagem do fgets: Lemos a linha digitada como texto comum. Assim, qualquer digitação errada é tratada com calma e o programa apenas pede o número de novo.
  • Subtrair '1': Como os caracteres '1' a '9' são sequenciais na tabela ASCII, subtrair '1' transforma o caractere diretamente no índice de 0 a 8 do nosso vetor.
  • Posição Livre: Checa se a casa está com espaço ' ' antes de confirmar a jogada.
